# Python Text-Based Escape Room

An interactive text-based escape room game developed in Python.

## Overview

Explore multiple rooms, discover clues, solve puzzles, collect numbers,
unlock a safe, and find the key needed to escape.

## Features

- Multi-room exploration
- Directional movement
- Interactive puzzles
- Inventory system
- Number collection and combination lock
- Locked/unlocked doors
- User command processing
- Interactive puzzle images

## How to Play

Run `main_code_escape.py` and follow the instructions displayed in the terminal.

Available commands include:

- `go north`
- `go south`
- `go east`
- `go west`
- `look desk`
- `solve desk`
- `look mirror`
- `solve mirror`
- `look note`
- `solve note`
- `open safe`
- `use key`
- `inventory`
- `digits`
- `show instructions`
- `quit`
